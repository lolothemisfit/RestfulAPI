# RESTful API

## Overview

This project is a RESTful API built using Java, Spring Boot, Spring Data JPA, and MySQL. The application provides full CRUD (Create, Read, Update, Delete) functionality through HTTP requests.

The API allows users to create records, retrieve data, update existing records, and delete records stored in a MySQL database.

HTTP requests are tested using Postman.

## Features

* Create new records
* Retrieve existing records
* Update existing records
* Delete records
* MySQL database integration
* RESTful endpoint architecture
* Spring Data JPA persistence layer

## Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* Maven
* Postman

## Learning Outcomes

This project helped strengthen my understanding of:

* REST API design principles
* HTTP request methods (GET, POST, PUT, DELETE)
* Database integration with Spring Boot
* Entity modelling with JPA
* Repository pattern implementation
